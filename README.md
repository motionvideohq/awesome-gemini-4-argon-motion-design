## How to use a prompt

1. Open a video's **Prompt** link and copy the prompt.
2. Give it to Gemini 4 Argon (in Claude Code, Cursor, or any agent that can write and run code), filling in any placeholders such as your product name.
3. Let it write the animation as code, then render it to video (Remotion, HyperFrames, or a headless browser with ffmpeg).

Want agents that already know timing, easing and choreography? See the [MotionVideo skill](https://motionvideo.xyz/motionvideo-skill?utm_source=github&utm_medium=readme&utm_campaign=awesome-gemini-4-argon-motion-design).
